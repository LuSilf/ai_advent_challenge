- Репликация (Master-Slave, Master-Master) для распределения чтения и повышения доступности:
  - Master обслуживает чтения и записи, реплицируя записи на слейвы, которые обслуживают только чтение. Это позволяет распределить нагрузку чтения между несколькими нодами.
  - При падении мастера система может работать в режиме only-read до восстановления/замены.
  - Слои-слои могут образовывать древовидную цепь репликации, усиливая масштабирование чтений.

- Вариант без раскрытия конкретных open-source инстр
